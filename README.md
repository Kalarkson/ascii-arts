# ASCII Art Generator

## Requirements

- Rust 1.70+ (edition 2021)
- Cargo package manager
- `libpng` development libraries (for image processing)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/ascii-art-generator.git
   cd ascii-art-generator
   ```

2. Build the project:
   ```bash
   cargo build --release
   ```

## Usage

2. Run the program:
   ```bash
   cargo run --release
   ```
